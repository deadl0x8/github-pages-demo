# GitHub Pages Static Website

## Overview

This project demonstrates how to host a simple static website using GitHub Pages.

The website consists of a basic HTML page with CSS styling and a small JavaScript interaction. Once the project is pushed to GitHub, GitHub Pages is used to publish the website.

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub Pages

## Project Structure

```
.
├── index.html
├── style.css
└── README.md
```

## Steps Followed

1. Created a simple HTML webpage.
2. Added CSS for styling.
3. Initialized a Git repository.
4. Pushed the project to GitHub.
5. Enabled GitHub Pages from the repository settings.
6. Verified that the website was successfully deployed.

## Website Features

- Responsive layout
- Clean user interface
- Interactive button using JavaScript
- Hosted for free using GitHub Pages

## Deployment

After enabling GitHub Pages, the website is available at:

```
https://YOUR_USERNAME.github.io/github-pages-demo/
```

## Outcome

This task helped me understand how static websites can be deployed using GitHub Pages and how changes pushed to GitHub are automatically reflected on the live website.
